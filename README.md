# React Helmet POC 🚀

This project is a **Proof of Concept (POC)** for using `React Helmet` to dynamically update the **title, meta tags, and SEO-related attributes** in a React application.

## 🛠 Features
- ✅ Dynamic page titles
- ✅ Meta tags for **SEO optimization**
- ✅ Simple **navbar, hero section, about section, and footer**
- ✅ Clean **CSS-based styling** (No Tailwind)
